# Calculator

A simple calculator that runs in the browser, built with HTML, CSS and JavaScript. No libraries and no frameworks.

**This project was made to practice JavaScript**, together with HTML and CSS. I wanted to work with the DOM, events and some basic logic without using `eval`.

**Live demo:** https://reisdan7.github.io/calculator

## Features

- Addition, subtraction, multiplication and division
- Decimal numbers
- Percent, clear (C) and delete (backspace) buttons
- Shows the previous number and the chosen operation above the result
- Handles division by zero without breaking
- Works with the keyboard too: numbers, `+ - * /`, `.`, `Enter`, `Backspace`, `Escape` and `%`
- Responsive layout for desktop and mobile

## What I practiced

- Selecting and updating elements with the DOM
- Click and keyboard events
- Event delegation
- Keeping the calculator state in variables
- CSS Grid for the keypad

## How to run

Download the project and open `index.html` in your browser.

```bash
git clone https://github.com/reisdan7/calculator.git
cd calculator
```
